Quickstart: Local GCloud CLI Setup

Follow these commands in your local powershell to initialize authorization: 

# 1. Download and run the Google Cloud SDK installer
(New-Object Net.WebClient).DownloadFile("https://dl.google.com/dl/cloudsdk/channels/rapid/GoogleCloudSDKInstaller.exe", "$env:Temp\GoogleCloudSDKInstaller.exe")
& $env:Temp\GoogleCloudSDKInstaller.exe

# 2. Initialize and login to Google Cloud account
gcloud init

# 3. Verify authenticated account
gcloud auth list

# 4. Trigger the deployment automation pipeline script
python deploy_gcp.py --project [PROJECT_ID] --instance [VM_NAME] --zone [ZONE]
